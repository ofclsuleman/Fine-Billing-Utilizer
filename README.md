## ✨ Features

- 🎬 Animated **splash screen** on startup
- 🔐 **Efficient login** — first-time users register with just a **business name**
- 🌙☀️ **Light & Dark modes** (switch anytime, no restart)
- 👥 **Customer management** — add, edit, delete, search + purchase history
- 🏭 **Supplier management** — add, edit, delete, search + purchase history
- 📦 **Products** — add with **optional** price & quantity, stock tracking
- 🧾 **Sales invoices** — multiple product entries, auto totals, stock decrease
- 🛒 **Purchase invoices** — multiple product entries, stock increase
- 📚 **Records** — track all sales & purchases, filter, search, view details
- 📊 **Dashboard** — totals, counts, recent invoices, low-stock alerts
- 💾 All data stored locally in **SQLite** (`fine_billing.db`)
- 📄 Invoice **export to text file**
